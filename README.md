I build the software that gets spacecraft down safely and check it against what NASA and ESA actually measured. Right now I'm rebuilding OSIRIS-REx's autonomous landing system from scratch (hazard-detection AI, navigation and a replay site) and reproducing Planck's cosmic microwave background results with the CLASS code. Space is the mission, and AI is the toolkit I use to get there.
